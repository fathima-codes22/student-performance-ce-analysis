# Student Performance Analysis

## About the Project
This is my first beginner-level Python project. It calculates students' total marks, average marks and grades.

## Technologies Used
- Python 3

## Features
- Calculates total marks.
- Calculates average marks.
- Assigns grades based on average marks.
- Displays a student performance report.

## Concepts Learned
- Variables
- Arithmetic operators
- Conditional statements
- Print statements

## Sample Output
- Student Name: Fathima
- Total Marks: 273
- Average Marks: 91.0
- Grade: A+
